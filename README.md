# NetPractice

## Description
NetPractice is a training project designed to teach fundamental networking concepts through hands-on configuration exercises.  
The goal is to correctly configure small networks by assigning IP addresses, subnet masks, default gateways, and routing rules so that all required machines can communicate.

The project consists of 10 levels, each introducing progressively more complex network topologies involving hosts, routers, and subnetting scenarios.

## Instructions
- NetPractice is solved directly through the online interface provided by 42.
- Your task is to complete all 10 levels and export the configuration of each one.

### Working on Levels
- Open the NetPractice interface from the 42 intranet project page.
- Configure IP addresses, subnet masks, gateways, and routing rules until the level is marked as solved.

### Exporting Configurations
- After solving a level, click “Export” in the interface.
- The platform generates a JSON configuration file containing all the values you entered.

### Submission Requirements
- You must submit 10 JSON configuration files, one for each level.
- All JSON files must be placed at the root of your repository.
- The repository must also include a README.md describing the project.

## Resources

### Networking Concepts Covered
This project introduces and reinforces core networking topics, including:

- IPv4 addressing
- Subnet masks and CIDR notation
- Subnetting and address allocation
- Default gateways
- Routing and routing tables
- Static routes
- LAN segmentation
- Routers vs. switches
- The OSI model (focus on layers 2 and 3)
- Connectivity rules and reachability analysis
